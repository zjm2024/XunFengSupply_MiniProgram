# 薰风经销商下单系统 HTML 原型

## 使用方式

直接双击 `index.html` 即可查看；也可在本目录运行：

```powershell
& 'D:\组件\node.exe' server.mjs
```

然后访问 `http://127.0.0.1:4173/`。

## 已实现页面与交互

- 极简首页：经销商身份条、商品下单、新闻资讯两个核心入口
- 经销商中心及业务服务：订单、充值、对账、流水、售后、发票、地址、对公凭证、子账号、安全、语言
- 新闻资讯与消息中心
- 购物车：商品 → 颜色 → 尺码三级分组、展开/收起和数量修改
- 商品目录、商品详情、参数与图文详情
- 多颜色 × 多尺码批量选规格
- 批量填数、复制数量到其他颜色、批量加入购物车
- 确认订单与提交确认弹窗
- 手机与平板响应式布局

## 响应式规则

- `< 768px`：手机单列，全屏业务流，操作栏固定底部。
- `≥ 768px`：平板首页双入口并列；经销商中心、商品详情、批量规格和结算使用双栏布局。
- 内容最大宽度 1180px，避免大平板横屏内容被过度拉伸。

## 文件说明

- `index.html`：所有原型页面结构
- `styles.css`：Design Tokens、手机/平板响应式样式
- `app.js`：页面导航、规格数量、批量填数、购物车和弹窗交互
- `assets/`：本地产品图片资源
- `server.mjs`：可选的本地静态预览服务
