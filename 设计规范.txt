# 薰风体育B2B经销商订货APP · 完整落地设计系统 Design System
基于你提供的移动端4屏UI截图提炼，适配**品牌总代→区域经销商**B2B拿货场景，逐条附带「适用场景/禁止用法」，指出现有UI不一致问题，末尾附带前端可用Design Tokens。

## 一、产品气质、目标用户、核心使用场景
### 1. 产品气质
商务稳重、克制专业、低娱乐化、强业务实用性；高级深红商务基调，摒弃电商花哨营销元素，突出授信、库存、批量订货、对账等B端专业属性；风格偏企业进销存工具，弱化C端商城氛围。
### 2. 目标用户
各地体育用品线下经销商老板、门店采购业务员、经销商内勤；年龄28~50岁，以务实商务人群为主，操作追求高效、批量操作、数据清晰。
### 3. 核心使用场景
1. 日常补货：快速搜索货号、调取历史补货清单批量下单；
2. 库存查询：查看单品尺码库存判断备货；
3. 订单管理：查看品牌审核进度、对账回款；
4. 售后处理：签收破损货品发起退换；
5. 账号管控：经销商老板创建子账号管控业务员下单权限。

## 二、从截图提炼现有视觉语言 & 当前UI存在的不一致问题
### 提取原生视觉语言
1. **主色**：深酒红 `#00B42A`(标注有误，实际顶部导航栏深红色 `#900B23`)、辅助橙色 `#F9500` 用于行动按钮；白底全局背景。
2. **布局**：底部4Tab常驻导航（首页/分类/订单/我的），卡片式内容容器，顶部搜索栏+品牌营销Banner区块。
3. **组件**：圆角卡片布局、矩形复选框批量选择、底部固定结算栏、分段Tab标签栏（订单页：待审核/待付款/待发货/售后）。
4. **交互特征**：购物车支持批量选中、批量改量；缺货SKU置灰禁用。
5. **风格**：无渐变花哨插画，极简实物商品图、线性图标。

### 当前UI现存不一致问题（重点修正项）
1. **主色混乱**：界面标题标注主色写 `#00B42A` 绿色，但顶部「我的中心」导航栏实际使用深红色，色彩定义冲突；
2. **按钮圆角不统一**：购物车「提交订货」橙色按钮为大圆角，顶部标签Tab是直角，卡片圆角中等，三种圆角规格混用；
3. **文字层级紊乱**：订单列表金额文字时而加粗、时而常规字重，无统一规范；
4. **头部样式差异化**：首页头部是红色渐变营销Banner，「我的」页面是纯红色纯色头部，没有统一头部容器规则；
5. **图标风格混杂**：首页快捷功能图标是填充圆角图标，导航Tab是线性图标，两套图标体系混用；
6. **留白间距不固定**：首页快捷功能模块内边距和购物车卡片内边距数值不一致。

# 三、完整 Design System 规范（每条含：适用场景 + 禁止用法）
## 1. 设计原则
### 原则1：业务优先，去除营销化
适用场景：全页面布局，优先展示库存、金额、批量操作按钮、订单状态等业务信息。
不要怎么用：禁止添加弹窗广告、满屏营销弹窗、弹窗优惠券、花哨动效。

### 原则2：高效批量操作
适用场景：购物车、商品列表、订单列表，默认支持多选、批量修改。
不要怎么用：仿照C端商城只能单选加入购物车，增加经销商补货操作步骤。

### 原则3：状态强区分
适用场景：SKU库存状态、订单审核状态、授信额度状态，用色彩直观区分正常/紧张/缺货/冻结。
不要怎么用：仅依靠文字描述状态，不用色彩辅助区分，增加识别成本。

### 原则4：商务克制极简
适用场景：所有页面、弹窗、空状态页面。
不要怎么用：使用渐变霓虹色、卡通插画、大面积装饰元素。

### 原则5：品牌权限管控可视化
适用场景：个人中心、商品规格区域，被禁用SKU、冻结账号必须视觉置灰锁定。
不要怎么用：禁用商品仍高亮可点击，造成经销商无效操作。

## 2. 色彩系统
### 主色板
| 色值 | 名称 | 用途（适用场景） | 禁止用法 |
| ---- | ---- | ---- | ---- |
| `#8C0F22` | 品牌商务红（主色） | 顶部导航栏、底部Tab选中态、头部个人中心栏、主要标题强调色 | 禁止用作大面积背景、普通按钮底色，避免视觉压迫 |
| `#F26422` | 行动橙（强调色） | 提交订货、结清账单、确认收货等高风险正向操作按钮 | 用作取消、驳回、禁用类按钮，造成用户误判 |
| `#009432` | 成功绿 | 订单已签收、账单结清、库存充足状态标签 | 用于警告、缺货状态 |
| `#F5A623` | 预警黄 | 库存紧张、授信额度即将用尽、账单即将逾期 | 代表正常可用状态 |
| `#E53935` | 危险红 | 订单驳回、账号冻结、已逾期欠款、缺货标签 | 用于确认、提交类正向按钮 |

### 中性色板（文本/背景/分割线）
| 色值 | 名称 | 适用场景 | 禁止用法 |
| ---- | ---- | ---- | ---- |
| `#FFFFFF` | 纯白背景 | 页面全局底色、卡片底色 | 深色模式以外场景禁止作为文字颜色 |
| `#F7F7F7` | 浅灰底色 | 列表行间底色、弹窗背景、空状态底色 | 用作卡片底色，造成层级粘连 |
| `#E8E8E8` | 分割灰 | 模块分割线、Tab分割线、卡片边框 | 作为正文文字颜色 |
| `#666666` | 次级文字 | 描述文案、备注信息、辅助说明文字 | 页面主标题、金额数字使用该色 |
| `#333333` | 正文黑 | 商品名称、订单标题、常规正文文字 | 浅色背景以外场景使用 |
| `#999999` | 禁用灰 | 缺货SKU、冻结按钮、失效文案置灰 | 正常可交互组件使用该颜色 |

### 语义色固定规则
1. 可用=绿色、紧张=黄色、缺货=红色；
2. 提交动作统一橙色，取消动作统一灰色。

## 3. 字体系统
统一字体：移动端默认系统字体 `PingFang SC / Inter`，不引入艺术字体。
| 字号 | 字重 | 适用场景 | 禁止用法 |
| ---- | ---- | ---- | ---- |
| 28px | Bold 700 | 页面大标题、订单总金额、授信额度数值 | 详情描述、辅助文案使用粗体大字号 |
| 24px | Medium 500 | 模块标题、商品名称、Tab标题 | 正文段落通篇使用该字号 |
| 20px | Regular 400 | 正文内容、规格名称、订单摘要文字 | 标题使用常规字重 |
| 16px | Regular 400 | 备注文案、辅助说明、时间文本 | 核心业务数据、金额使用16px字号 |
| 12px | Regular 400 | 状态标签小字、页脚备注 | 正文主体文字使用12px |

字体层级硬性规则：金额数字一律加粗展示；状态标签统一最小字号。

## 4. 间距与栅格系统（移动端375基准栅格）
基准栅格单位：`8px`，所有间距为8的倍数
| 间距值 | 名称 | 适用场景 | 禁止用法 |
| ---- | ---- | ---- | ---- |
| 8px | XS间距 | 卡片内部文字与文字间距、标签之间间距 | 卡片外边距、模块间距使用8px |
| 16px | S间距 | 卡片内边距、列表上下间距、弹窗内边距 | 模块与模块之间大留白使用16px |
| 24px | M间距 | 模块和模块之间间距、Tab栏与上方内容间距 | 卡片内部留白使用24px造成空旷 |
| 32px | L间距 | 页面顶部导航与首个模块间距、底部Tab上方留白 | 卡片内部、列表行间使用32px |
| 40px | XL间距 | 空状态页面上下大留白 | 普通业务页面模块间距使用XL |

页面安全边距：页面左右固定留白 `16px`，所有内容不能贴左右屏幕边缘。
不要怎么用：不同模块混用非8倍数间距（10px、14px），造成页面杂乱。

## 5. 圆角、边框、阴影规范
### 圆角规则
| 圆角半径 | 适用组件 | 禁止用法 |
| ---- | ---- | ---- |
| 4px | 状态标签、复选框、小按钮 | 卡片、弹窗使用4px小圆角 |
| 8px | 商品卡片、订单卡片、功能模块卡片（全局卡片统一8px） | 行动主按钮使用8px圆角 |
| 12px | 弹窗容器、底部弹窗、提交按钮、结算栏按钮 | 列表卡片使用12px大圆角 |
| 0px | 顶部Tab分段标签栏 | 卡片容器使用直角 |

### 边框
1. 常规卡片：无边框，依靠底色区分层级；
2. 选中状态：1px `#8C0F22` 主色边框；
3. 分割线：1px `#E8E8E8` 水平分割线，只做横向分割。
禁止用法：卡片四周增加彩色边框、多重边框。

### 阴影
| 阴影规格 | 适用场景 | 禁止用法 |
| ---- | ---- | ---- |
| 柔和阴影：`0 2px 8px rgba(0,0,0,0.06)` | 弹窗、底部悬浮结算栏、悬浮按钮 | 普通商品卡片增加阴影，页面厚重杂乱 |
| 无阴影 | 列表卡片、普通模块卡片 | 全部卡片统一增加阴影 |

## 6. 核心组件规范（结合截图现有组件）
### 组件1：底部Tab导航（首页/分类/订单/我的）
适用场景：全局常驻底部导航。
结构：线性图标+下方文字，选中态图标+文字变为品牌红`#8C0F22`，未选中`#999`。
不要怎么用：Tab使用填充图标、Tab添加渐变背景、动态动效切换。

### 组件2：顶部搜索栏
适用场景：首页顶部，全局商品检索。
结构：白色圆角容器、放大镜线性图标、浅灰色占位文字「搜索货号/商品名称」。
不要怎么用：搜索栏增加营销标语、弹窗热搜推荐。

### 组件3：快捷功能九宫格（首页待付款/库存查询/快速补货）
适用场景：首页核心功能入口，2行4列布局。
结构：圆形底色图标+下方文字，底色使用浅品牌红色。
不要怎么用：功能图标使用不同形状底色、加入动态动画。

### 组件4：购物车卡片（核心业务组件）
适用场景：购物车页面商品条目。
结构：左侧复选框 + 商品缩略图 + 商品名称+颜色尺码规格 + 单价 + 加减数量控件。
规则：缺货SKU整行置灰，复选框禁用。
不要怎么用：购物车卡片增加点赞、收藏等C端冗余功能。

### 组件5：分段Tab标签（订单页：待审核/待付款/待发货/售后）
适用场景：订单、售后列表顶部分类标签。
规则：直角Tab，选中项下方红色下划线高亮。
不要怎么用：Tab做成胶囊圆角样式、选中色块铺满Tab。

### 组件6：底部悬浮结算栏
适用场景：购物车页面底部固定悬浮。
结构：左侧选中数量+合计金额（加粗橙色）、右侧橙色「提交订货」按钮。
不要怎么用：结算栏跟随页面滚动、隐藏金额信息。

### 组件7：弹窗（库存弹窗、批量改量弹窗、审核驳回弹窗）
适用场景：弹出详情、批量操作、消息提醒。
规则：居中弹窗、圆角12px、白底柔和阴影。
不要怎么用：全屏弹窗、弹窗背景模糊加花哨特效。

## 7. 状态规范
### 商品SKU状态
1. 库存充足：正常高亮可勾选；
2. 库存紧张：底色浅黄背景提醒，可下单；
3. 缺货/禁售：整体`#999`置灰，复选框、数量按钮全部禁用，不可选中。
适用场景：商品详情、购物车规格列表。
禁止：缺货SKU仍允许加入购物车。

### 订单状态
1. 待审核：灰色标签；
2. 待付款：橙色标签；
3. 待发货：蓝色标签；
4. 已签收：绿色标签；
5. 售后中：黄色标签；
6. 已驳回/关闭：红色标签。
适用场景：订单列表、订单详情头部。
禁止：不同订单状态使用相同颜色标签。

### 账号状态
1. 正常：全部功能开放；
2. 额度不足：下单按钮置灰弹窗提醒；
3. 账号冻结：拦截登录，弹出提示文案。

## 8. 图标 & 插画规范
1. 图标统一：线性线条图标，线条粗细 `1.5px`，两套图标统一为线性风格（修复当前填充+线性混用问题）；
2. 功能图标尺寸统一 24px，Tab图标尺寸 22px；
3. 插画：仅空状态页面使用极简线性商务插画（无卡通形象）；
适用场景：所有按钮、导航、功能入口。
不要怎么用：渐变图标、3D图标、卡通表情包插画。

## 9. 文案语气规范
整体风格：严谨直白、商务中性、无口语化话术。
1. 操作文案：动词直白「提交订货、结清账单、发起售后、批量修改」；
2. 提示文案：说明原因+解决方案，例：`授信额度不足，请结清账单后继续下单`；
3. 错误文案：不使用网络用语、表情符号；
适用场景：弹窗提示、按钮文字、状态说明。
禁止：卖萌文案、营销话术、感叹号堆砌。

## 10. 禁用规则 / 设计红线
1. ❌ 禁止增加优惠券、积分、会员玩法，业务替换为信誉授信体系；
2. ❌ 禁止经销商修改商品售价，所有价格由品牌后台下发；
3. ❌ 禁止缺货SKU可选中下单；
4. ❌ 禁止弹窗自动推送营销广告；
5. ❌ 禁止页面出现电商秒杀、弹窗抽奖等娱乐化组件；
6. ❌ 禁止不同页面卡片圆角、间距、色彩规则不统一；
7. ❌ 禁止经销商之间互相调货下单入口。

# 四、前端可用 Design Tokens
## 1. CSS Variables（全局样式变量，可直接引入项目）
```css
:root {
  /* 色彩系统 */
  --color-primary: #8C0F22;
  --color-action: #F26422;
  --color-success: #009432;
  --color-warning: #F5A623;
  --color-danger: #E53935;

  --color-bg-white: #FFFFFF;
  --color-bg-gray: #F7F7F7;
  --color-border: #E8E8E8;
  --color-text-main: #333333;
  --color-text-sub: #666666;
  --color-text-disable: #999999;

  /* 字号 */
  --font-xl: 28px;
  --font-lg: 24px;
  --font-md: 20px;
  --font-sm: 16px;
  --font-xs: 12px;

  /* 间距 8px基准 */
  --space-xs: 8px;
  --space-s: 16px;
  --space-m: 24px;
  --space-l: 32px;
  --space-xl: 40px;

  /* 圆角 */
  --radius-sm: 4px;
  --radius-card: 8px;
  --radius-btn: 12px;

  /* 阴影 */
  --shadow-popup: 0 2px 8px rgba(0, 0, 0, 0.06);

  /* 页面安全边距 */
  --page-padding: 16px;
}
```

## 五、现有UI修复整改清单（对应前面不一致问题）
1. 修正色彩定义错误：删除错误绿色主色标注，统一品牌主色为酒红`#8C0F22`；
2. 统一圆角：所有商品/订单卡片圆角固定 `8px`，操作按钮圆角12px，Tab改为直角；
3. 图标归一：首页功能图标全部改为线性样式，和底部Tab图标风格统一；
4. 头部容器统一：首页Banner、我的页面头部全部采用纯色品牌红头部结构；
5. 文字统一规则：所有金额数字固定加粗28号字，辅助文案统一16px灰色；
6. 全局间距全部替换为8px倍数，消除杂乱内边距。
